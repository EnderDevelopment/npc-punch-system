# NPC Punch System

Summon and animate NPCs with punch animations in FiveM

## Features

- Summon NPCs with a GUI
- NPCs can walk and perform punch animations

## Requirements

- FiveM server
- ESX framework

## Installation

1. Download the script
2. Place the script in your FiveM resources folder
3. Add `start npc_punch_system` to your server.cfg

## Usage

1. Press the E key to open the NPC menu
2. Click 'Summon NPC' to summon an NPC

## Configuration

- `Config.NPCModel`: The model of the NPC
- `Config.NPCAnimation`: The animation the NPC performs when idle
- `Config.PunchAnimation`: The punch animation the NPC performs
- `Config.GUI`: The GUI settings for the NPC menu
